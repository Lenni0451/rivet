# Rivet
Work in progress UI library written in Java.\
The library is in early stages of development, so expect breaking changes and missing features.\
Don't let this stop you from using it, I would love to get feedback and contributions.

## Usage
Currently, there is no official release and no real documentation.
Your best shot at using rivet at this point is to look at the examples in the `examples` folder and the source code itself.\
If you have any questions, feel free to reach out by opening an issue or using the discussion board.

If you've used AWT and Swing before, you should feel right at home with rivet.
I took inspiration from those libraries and tried to make rivet what I wish AWT and Swing were.

### Tests
I personally hate writing tests and rather focus on writing the actual code.
For this reason, I let AI write the tests for me. I do not fully review all the tests, I only check for obvious mistakes and errors.
This means there might be some tests that are not correct, do not test the intended functionality or do nothing at all.
While this isn't ideal, I believe it is better than not having any tests at all.\
If you find any tests that are incorrect or do not test the intended functionality, please let me know.
